# INMA Hotels Outfit LLC Website

Premium corporate B2B procurement and trading website for INMA Hotels Outfit LLC, built with Next.js, Tailwind CSS, Framer Motion, GSAP, and lucide-react.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Routes

- `/`
- `/about`
- `/solutions`
- `/industries`
- `/products`
- `/procurement-services`
- `/hospitality-solutions`
- `/utility-commercial-supply`
- `/catalog`
- `/projects`
- `/contact`
- `/api/catalog`

## Notes

- The active company logo lives at `public/assets/inma/inma-the-progress-logo.png`.
- The catalog download is generated by the Next.js API route at `/api/catalog`.
- Visual imagery uses remote premium hospitality, commercial, logistics, and industrial photography URLs.
- RFQ forms are functional client-side lead capture interactions and can be wired to CRM/email later.
